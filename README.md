# Bharat HeritageX 🇮🇳

**A Smart Digital Platform to Preserve and Explore India's Rich Cultural Heritage**

🔗 **Live Demo:** [Visit Bharat HeritageX](https://bharat-heritage-x.vercel.app/)  
💻 **Source Code:** [GitHub Repository](https://github.com/madhav-kohli/Bharat-HeritageX)

Bharat HeritageX is an interactive web platform designed to showcase India's historical monuments, cultural traditions, and heritage destinations through an engaging digital experience.
