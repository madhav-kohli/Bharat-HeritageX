# Bharat HeritageX 🇮🇳

**A Smart Digital Platform to Preserve and Explore India's Rich Cultural Heritage**

🔗 **Live Demo:** [Visit Bharat HeritageX](https://bharat-heritage-x.vercel.app/)  
💻 **Source Code:** [GitHub Repository](https://github.com/madhav-kohli/Bharat-HeritageX)

Bharat HeritageX is an interactive web platform designed to showcase India's historical monuments, cultural traditions, and heritage destinations through an engaging digital experience.


## ✨ Key Features

- 🏛️ **Heritage Exploration:** Discover India's historical monuments, cultural landmarks, and traditions.
- 🗺️ **Interactive India Map:** Explore heritage destinations through an interactive map experience.
- 🤖 **AI-Powered Chatbot:** Get assistance and information about Indian heritage through an integrated AI chatbot.
- 🔍 **Smart Search & Filtering:** Find heritage destinations using search and category-based filtering.
- 📍 **Map Integration:** Explore heritage locations using Google Maps integration.
- 🖼️ **Gallery & Destination Details:** Browse heritage visuals and learn more about cultural destinations.
- 🌐 **Multilingual Experience:** Support a more accessible heritage exploration experience across languages.
- 📱 **Responsive Interface:** Access the platform across desktop and mobile screen sizes.
- 🏛️ **Interactive 3D Heritage Models:** Integrated Three.js to render 3D models of heritage structures, creating a more immersive and engaging cultural exploration experience.

## 🛠️ Tech Stack

- **Frontend:** React.js, JavaScript, Bootstrap / Reactstrap
- **Routing:** React Router
- **APIs & Integrations:** Google Maps API, AI chatbot integration
- **HTTP Requests:** Axios
- **3D Visualization:** Three.js
- **Deployment:** Vercel

## 💻 Run Locally

```bash
git clone https://github.com/madhav-kohli/Bharat-HeritageX.git
cd Bharat-HeritageX
npm install
```

Create your local `.env` file with the required API configuration, then start the development server using the script defined in `package.json`.

## 🎯 Project Objective

To make India's rich cultural and historical heritage easier to discover through an interactive digital platform that combines modern web technologies, maps, and AI-assisted exploration.
